## One-command operator master

Run the local Next.js Studio with Playwright Chromium and FFmpeg installed:

```bash
npm run dev
npm run motion:signature -- --lang en --format portrait \
  --out out/promptence-signature-en.mp4
# Optional: --voice ./assets/approved-voice.wav --reference ./approved/reference.mp4
# Optional: --screen ./approved/promptence-real-screenshot.png, after setting that shot's kind to screen
```

The command requests the exact same signature project from the public **stateless and zero-key** `GET /api/motion/signature` endpoint, writes editable `.motion.json` and delegates encoding to the existing Motion Master pipeline. It requires real FFmpeg QA, not a Vercel serverless movie job.
