## Artistic experiment — not a slideshow

- **Source-authentic only:** read-only `https://promptence.tech/` public homepage capture mapped onto the physical 3D model. No fake AI metrics, customers, source sites or outcomes.
- **Actual camera:** authored dolly, yaw and parallax through Three.js perspective geometry.
- **Real 3D device:** bevelled aluminium chassis, glass, graphite shell, studio reflection map, moving softbox highlights.
- **Product-screen transformation:** five UV-exact full-height photographic screen sections lift into real 3D and reveal depth. This was simplified from ten overlapping cards after frame-by-frame visual review, to protect screenshot readability.
- **No generic green spheres**, floating fake recommendation cards, ornamental particle fields or text over the real product's own bold hero headline.
- Original local score built from clean synthesis, never downloaded proprietary songs. Committed to `scripts/motion/soundtrack-promptence-v8.py`.
- Clearly marked five-second **art direction quality gate**, not a 30s advertisement. Browser preview auto-requests a same-origin cached public-only capture. No private login or customer data.
- Desktop/mobile review available directly in the existing Motion Studio. Production export generated by `scripts/motion/render-promptence-v8.mjs`, with strict URL and source constraints.

## Art direction assessment / next requirement

Machine-valid MP4 is not proof of reference parity. The macro camera and authentic interface are a stronger foundation than the abstract orbital sequences, but the panel segmentation still needs a finer authored material treatment, stronger optical design and professional sound/director approval before expanding to 25-30s. **`publicationApproved: false`.**

The V8 proof was never merged to `main`; this is a review build, not a public advertising release. Separate GitHub Actions GPU runner status remains a distinct release gate. No subscription, credits or private API keys were spent.

## Reproduce

```bash
npm install
npm run build
npm run start -- -H 127.0.0.1 -p 3000
# In separate terminal (Playwright + compatible Chromium + FFmpeg)
python3 scripts/motion/soundtrack-promptence-v8.py
npm run motion:cinema:v8 -- out/PROMPTENCE_V8_5S.mp4 \
  --capture-public --fps 24 \
  --music out/PROMPTENCE_V8_ORIGINAL_SOUNDSCAPE.wav \
  --chromium /path/to/chromium
```
