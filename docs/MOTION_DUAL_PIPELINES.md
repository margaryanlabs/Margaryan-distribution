# MARGARYAN MOTION OS — TWO PRODUCTION PIPELINES

This upgrades the existing Studio in-place. No new project or rewrite. Two modes at /motion?mode=cinematic and /motion?mode=quick share the existing 13 portfolio brand identities and actual source-verified assets.

## 01 — CINEMATIC STUDIO

The existing procedural Canvas film engine is preserved: 2–8 scene timeline, logo staging, optional real screenshot import, original procedural motion, Armenian/Russian/English text, downloadable subtitles, reference comparison, measured contact-sheet QA and browser media recording. Separate CLI motion:master provides workstation Chromium + FFmpeg H.264/AAC master when verified by the operator.

Limitations: This is not yet true high-end photoreal cinematic generative production. Original reference and strongest V3 director's cut remain separate baseline artifacts. Code and Vercel builds alone do not prove creative excellence.

## 02 — QUICK STUDIO

A new independent working video editor, not merely a button linking to an external service. It composes actual local video/photo footage per shot with native-script typography, original shared brand logo, local 30fps preview and MediaRecorder output.

Includes:
- Editable 2–8 shot storyboard with Armenian-first MEQENA **platform acquisition** copy rather than advertisements for individual cars.
- 13 shared brand IDs and verified real logos when available.
- Accepts local MP4/WebM/MOV/PNG/JPEG/WebP including explicitly downloaded AI-generated video from Higgsfield or another provider.
- Source files are not uploaded to our servers, CDN, GitHub or localStorage. Quick JSON persists timing/copy only, and media must be reattached after reopening.
- Browser exports WebM or MP4 only where supported by the device. An optional user-uploaded music track is mixed locally and export fails, rather than silently ignoring, when the audio cannot be prepared.
- Every Quick shot must have real sourced media before export. No fictional AI results, made-up marketplace listings, fabricated statistics or stock footage automatically downloaded.
- A JSON production receipt lists source filenames, editorial text and review requirements. Human approval required for licenses, privacy, sound and publishing.

Quick currently does NOT call the Higgsfield API. Paid AI video generation remains an explicit external process, and finished footage can be imported. No secret cloud account connection or hidden credit consumption.

## Brand source

The original public official MEQENA emblem has been copied byte-for-byte from Shtapauto's public-facing source SVG into an allowlisted asset path in Motion. The MEQENA color palette was corrected to its existing black/red look in the shared brand info. Private GitHub contents and customer data have not been published.

## Quality standard

Film quality is not measured in PR counts, scene numbers or automated QA grades. Each film must be judged against (1) the original user-supplied reference, and (2) our best earlier V3. We must critically inspect framing, camera, legibility, timing, sound, production source authenticity and truthful claims before marking a film publishable.

## Manual acceptance gates

1. Test switching between both modes at /motion, including direct deep links and browser back.
2. Confirm Cinematic drafts survive switching, unchanged.
3. Load Quick default MEQENA/Armenian platform-sale storyboard.
4. Attach local source to each shot, verify live preview and scene selection.
5. Change title/crop/duration; save and import JSON, then reattach media.
6. Confirm source-gate blocks export when any shot lacks media.
7. Export all sourced shots and listen/watch exported video on a second device.
8. Confirm same-origin MEQENA official mark loads and protected operator endpoints remain protected.
9. Confirm Vercel preview/production build status and meaningful browser runtime checks.
10. Secure human authorization before public distribution; neither mode posts automatically.

This is a real two-mode production foundation; it is not yet a complete pro cinema suite or direct Higgsfield integration.
