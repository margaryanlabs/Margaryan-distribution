# Motion OS — Keyless Production Desk

This is an **in-place upgrade** of the existing `/motion?mode=cinematic` scene-based Canvas renderer. `/motion?mode=quick` is deliberately unchanged and still accepts user-supplied real footage. The source-first Proof Director remains a separate workflow.

## Real functionality shipped

- Scene inspector now directs **the actual frame output**: camera treatments (original / locked / push in / pull out / drift), per-cut transition (auto / hard / dissolve / vertical / diagonal), motion strength from 0–100%. These options survive sanitization, JSON save/re-import and offline deterministic render. Approved logos and glyphs are outside the camera transform.
- Shot order can be changed, selected shot duplicated, and narration cues customized shot by shot without overwriting the visible headlines.
- **Director Pack** downloads a JSON cue sheet with timeline timestamps, camera/transition notes, estimated voice duration and review warnings plus a plain-text voice script. Word-count timing is only a planning estimate: do not claim measured speech sync.
- Optional **local licensed music** is mixed into the browser video and automatically lowered under imported narration, with fade-in/fade-out and separate voice/music faders. Existing procedural soundtrack remains a separate toggle. No third-party footage/music is fetched.
- Existing imported narration is still **uploaded by the operator**, not generated by the site. This preserves user consent for voice recordings and avoids fake provider claims.
- Existing source-first screen shots, brand assets, QA, subtitles and export stay intact.

## How to use without keys

1. Open `/motion?mode=cinematic` and enter your brief. The local director creates an **editable procedural storyboard**, not a model-generated film.
2. Select a shot, adjust camera, transition, intensity and narration cue in **DIRECTOR DESK**. Reorder, duplicate and refine each scene.
3. Add your own speech file (MP3/WAV/M4A) and optionally licensed music. Adjust voice/music mixing. For narration timing, use the fit-film control and listen to the final recording.
4. Export **DIRECTOR PACK** for a timecoded production specification. Upload approved real interface screenshots to replace purely conceptual visuals when applicable.
5. Preview, run Quality Director, then export locally. Browser recording may create WebM; the existing `motion:master` offline CLI provides deterministic H.264/AAC MP4 when FFmpeg and Chromium are available.

## Optional open-source neural narration (operator machine, no keys)

A keyless **Chatterbox Multilingual V3** adapter is included in
`scripts/motion/local-chatterbox-voice.py`. It is NOT deployed on Vercel and
is NOT wired into the browser Generate button. It produces a reviewable
single WAV with silence between shots according to the Director Pack timestamps.
It fails visibly instead of squeezing or cropping words to fit.

On a GPU-equipped machine with Python and compatible PyTorch:

```bash
pip install chatterbox-tts torch torchaudio
python scripts/motion/local-chatterbox-voice.py \
  motion-promptence-production-pack.json narration.wav --device cuda --lang ru
# Review/listen to the WAV, then import it under NARRATION on /motion.
```

To use a reference voice, add `--reference /path/to/authorized-voice.wav`
ONLY with permission from its owner. The model weights download when first
used and require disk space and powerful hardware; software being free does not
make hosted CPU/GPU time free. Russian/English are supported; Armenian is NOT
among Chatterbox Multilingual's 23 supported languages. Use separately recorded
or properly licensed Armenian narration for HY films.

## Explicit limitations

- No OpenAI, Claude, ElevenLabs, Chatterbox or CosyVoice account was connected. No API keys were created.
- This change does **not** integrate GSAP, Three.js, Theatre.js or Remotion as live production dependencies. The new camera treatments are implemented in the existing deterministic Canvas engine to avoid breaking existing masters. These tools may be introduced in separate, render-verified steps.
- Browser Studio does not generate TTS. An optional Chatterbox CLI script can generate a **local** approved narration WAV on suitable hardware, to be imported by the operator. It has not been runtime-tested on a GPU in this PR.
- No video-provider generation, hosted render worker, 3D photorealism, operator account, auto-publishing or unlimited free GPU credits are claimed.
- The product site must be tested in real desktop/mobile browsers and sampled exported clips must be listened to/viewed before describing them as production-quality. Passing code checks is not artistic certification.

## Technical verification

`npm run motion:test-production` checks the bounded schema, cue ordering, voice text, default sanitization and invalid-input boundaries. Existing `npm run typecheck` / `npm run build` / motion tests continue to run in CI.

For future integration with offline free neural TTS (e.g. Chatterbox / CosyVoice), implement a separate, opt-in job worker that converts approved text to an audio file and returns it for import. Do **not** run large model weights in a public Vercel serverless request. Rendering and voice providers need real hardware capacity even when their model software is free.
