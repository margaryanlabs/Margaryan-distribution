## Artistic-quality honesty

This **proves that actual Three.js scene geometry, lighting and animation can be encoded as film**. It does NOT establish parity with the photoreal reference image the owner likes. The laptop model, light, terrain and typographic panels look stylized and need further calibrated materials, realistic modeling/texture work, improved typography, sound mix and human review. The five-second V8 was rejected as underwhelming; V9 is an eight-second draft for comparison, not a finished 30-second premium advertisement.

Do not claim finished Apple-level commercial, guaranteed customer growth or user sign-off. `publicationApproved: false` remains the source-of-truth QA flag. The PR is draft and has not been merged into production.

## Repeatable master

```bash
npm install
npm run build
npm run start -- -H 127.0.0.1 -p 3000
# Separate terminal: Node22, Playwright Chromium with WebGL/SwiftShader and ffmpeg required.
python3 scripts/motion/soundtrack-promptence-v9.py
npm run motion:cinema:v9 -- out/PROMPTENCE_V9_8S.mp4 \
 --capture-public --fps 24 --music out/PROMPTENCE_V9_ORIGINAL_SCORE.wav \
 --chromium /absolute/path/to/chromium
```
