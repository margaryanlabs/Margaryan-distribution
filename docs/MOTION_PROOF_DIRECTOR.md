# MARGARYAN MOTION OS — SOURCE-FIRST PROOF DIRECTOR

October 11, 2026 · First implementation tranche: **one honest, inspectable ten-second pilot**, not another full-length "cinematic" claim.

## Root problem addressed

The previous 168-second Promptence edits were mainly static images with zoom/pan and primitive speech synthesis. Their video codec, frame size, and numeric motion checks did not demonstrate craft quality.

This changes the production order:

**Product source capture → director-controlled moving composition → exact-frame export → real recorded voice → mobile review → approval → only then scale to a long film.**

## Implemented

- **`/motion/proof`**: dedicated mobile-friendly proof director within the *existing* Margaryan Distribution Next app. Explicit third path from both original Cinematic and Quick Studio, preserving their existing drafts and renderers.
- Requires an **owner-approved real PNG/JPEG/WebP product screenshot**. Without source, preview and browser export are blocked. Source bytes stay inside the browser tab; no upload, persistence, customer metadata or external AI generation.
- `lib/motion/proof-film.ts`: one **10-second deterministic canvas compositor**, three deliberately different, time-addressable editorial acts:
  - 0.00–2.42s: controlled kinetic hook with a travelling real product surface;
  - 2.42–7.55s: hard visual contrast to light editorial with purposeful source-pixel camera motion and no fake score cards;
  - 7.55–10.00s: original verified brand logo and one explicit CTA.
- Local playback/scrub/shot navigation; browser **review-only 540×960 WebM**, silent (no low-quality autogenerated TTS).
- Native operator-only **1080×1920 H.264/30 FPS MP4** from exactly the same frame renderer: `npm run motion:proof`. Playwright + FFmpeg, no upscale, no Python/Pillow/PanZoom slideshow.
- Optional **approved** pre-recorded narration/music: NO Flite, NO pitch/time compression, NO fake speech. Narration >9.7s is rejected rather than sped up.
- FFprobe verification, source file constraints, local contact sheet and JSON report. Reports state that aesthetic and voice performance require human approval.
- Explicit /motion/proof public-only proxy allowlist; no CRM or private API exposure.

## Operator workflow

```bash
# On a capable machine with Node 22+, Chromium, Playwright and FFmpeg:
npm install
npm install --no-save playwright
npm run dev

# Capture actual official public Promptence website. Fixed allowlist, isolated
# anonymous browser, screenshots + checksums, human approval required:
npm run motion:capture -- --brand promptence --out out/approved-candidates

# 1. Inspect the screenshot and capture manifest. Verify correct product,
# current live content, no customer data and rightful brand use.
# 2. On /motion/proof, upload out/approved-candidates/promptence-desktop.png
#    or mobile capture and inspect all three story beats.
# 3. Render the same film with real native frames:
npm run motion:proof -- --screen out/approved-candidates/promptence-desktop.png \
  --out out/promptence-proof-10s.mp4

# Optional ONLY after authentic, licensed narration is recorded:
npm run motion:proof -- --screen out/approved-candidates/promptence-desktop.png \
  --voice ./approved/real-voice.wav --music ./approved/licensed-score.wav \
  --out out/promptence-proof-10s-voiced.mp4
```

## Quality gate — must be completed before claiming "premium"

1. **Source**: screenshot manifest points to official Promptence and matches current live page. Reviewer confirms no private data, customer names or fictitious provider results.
2. **Frame-level motion**: compare first, middle, last frame in each act and watch full clip at 1× on phone. No static-slide/fake-3D disguises; explain each move's narrative purpose.
3. **Legibility**: inspect native 1080×1920 frames plus actual 390px mobile viewing. Read every CTA and check 9:16 platform safe areas. Avoid meaningless microtype.
4. **Camera**: screenshot integrity remains unchanged; aspect ratio must be preserved. Motion directs attention rather than making random shapes.
5. **Color / pacing**: distinct hard contrast act transitions are editorial intentional; verify against user's original reference instead of self-reported "premium" score.
6. **Audio**: any speech must be a human-approved, natural AI recording or licensed human voice with corrected pronunciation and alignment. No Flite/TTS fallback; native speaking speed untouched.
7. **Provenance**: report labels a web page screenshot as webpage capture, never as live provider result, account dashboard, client outcomes or quantified rank improvement.
8. **Technical**: ffprobe stream H.264 1080×1920, exact 10 s, complete frames, no crashes; visual review still required.

## Unresolved and explicitly NOT claimed

- This is **not** a universal Remotion/After Effects replacement, not a Hollywood studio and not a photoreal AI video generator.
- True interaction recordings, motion paths over multi-screen product use, editable keyframes, transition audio cues, phoneme-level forced alignment, and scalable Remotion/GPU rendering remain subsequent improvements.
- The public screenshot requires owner clearance and *does not* establish live product usage. No paid AI generation or footage publishing is performed.
- A READY Vercel build only proves build/type-check viability; it does not prove an exported film looks good. A final **review of an actual MP4** is mandatory before expanding to 2–3 minutes.

**Stop condition:** if the owner does not approve the ten-second sample, DO NOT produce a longer film.
